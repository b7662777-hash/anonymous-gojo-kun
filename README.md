# Anonymous Gojo-Kun Portfolio

Personal portfolio for Anonymous Gojo-Kun — Android ROM development, systems engineering, applications, AI tooling and security research.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

Import this repository into Vercel. No environment variables are required for the current static frontend.

## Customize

Edit project data and links in `app/page.js`.
Edit the visual system in `app/globals.css`.
Edit metadata in `app/layout.js`.
